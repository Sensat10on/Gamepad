# Политика конфиденциальности — Bluetooth GamePad & Mouse

Дата последнего обновления: 12 сентября 2026 г.

## Кратко

Приложение **не собирает, не хранит и не передаёт** никакие персональные данные. У приложения
вообще нет разрешения `android.permission.INTERNET`, то есть оно технически не может отправить
данные по сети.

## Какие данные обрабатываются

Приложение работает полностью на устройстве. Оно использует:

- **Bluetooth.** Разрешения `BLUETOOTH_CONNECT`, `BLUETOOTH_SCAN`, `BLUETOOTH_ADVERTISE`
  (Android 12+) и устаревшие `BLUETOOTH`, `BLUETOOTH_ADMIN`, `ACCESS_FINE_LOCATION`
  (Android 11 и ниже, только для поиска устройств) нужны, чтобы зарегистрировать телефон как
  Bluetooth HID-устройство, показать список сопряжённых устройств и подключиться к выбранному
  хосту. Через Bluetooth передаются только HID-отчёты: состояния органов управления
  (оси стиков, триггеры, кнопки) и относительные смещения курсора. Никакие файлы, контакты,
  тексты или идентификаторы не передаются.
- **Изображения, выбранные пользователем.** Фоновое изображение и изображение на корпусе
  геймпада выбираются через системный файловый диалог. Приложение сохраняет только ссылку
  (content URI) на выбранный файл и читает его для отображения. Изображения не копируются
  на серверы и никуда не отправляются.
- **Настройки.** Профиль контроллера, чувствительность, мёртвая зона, цвета, язык, параметры
  тачпада и выбранные изображения хранятся локально в приватном хранилище приложения
  (Android DataStore) и удаляются вместе с приложением.

## Что приложение НЕ делает

- Не собирает аналитику и статистику использования.
- Не показывает рекламу и не содержит рекламных SDK.
- Не использует сторонние SDK, передающие данные.
- Не запрашивает доступ к контактам, микрофону, камере, геолокации (на Android 12+),
  файлам вне выбранных пользователем изображений.

## Разрешения и зачем они

| Разрешение | Назначение |
|---|---|
| `BLUETOOTH_CONNECT` | регистрация HID-профиля и подключение к сопряжённому хосту |
| `BLUETOOTH_SCAN` (`neverForLocation`) | поиск сопряжённых и новых устройств |
| `BLUETOOTH_ADVERTISE` | видимость телефона для сопряжения |
| `BLUETOOTH`, `BLUETOOTH_ADMIN`, `ACCESS_FINE_LOCATION` | то же самое на Android 11 и ниже |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_CONNECTED_DEVICE` | удержание активной HID-сессии в фоне |
| `POST_NOTIFICATIONS` | обязательное уведомление о работе фоновой службы |
| `VIBRATE` | тактильная отдача при нажатии кнопок |

## Дети

Приложение не предназначено специально для детей и не собирает данные ни о каких
пользователях, включая детей.

## Изменения

Если политика изменится, обновлённая версия будет опубликована по этому же адресу с новой
датой.
